## Summary

This plan implements the execution layer that publishes approved Facebook posts from `/Approved/facebook/` to Facebook via Playwright browser automation. The executor detects approved files, validates frontmatter, publishes content to Facebook, moves successful posts to `/Done/facebook/`, and logs all attempts to `/Logs/facebook/`. Failed posts remain in `/Approved/facebook/` with error metadata for retry.

**Key Design Principle**: Vault-first, file-driven architecture. All state is determined by file location. No database, no in-memory state beyond processing.

## Section 1: Approved File Detection

### 1.1 Detection Strategy

Two modes supported (configurable):

1. **Watcher Mode** (default): Uses `watchdog.observers.Observer` to monitor `/Approved/facebook/` for new files.
2. **Poll Mode**: Periodic directory scan (fallback for environments where inotify is unreliable).

**Detection latency target**: 30 seconds (FR-001).

### 1.2 Detector Module

```python
# src/facebook_publisher/detector.py

class FacebookApprovedDetector:
    """Detects approved Facebook posts in /Approved/facebook/.

    Monitors for:
    - New files created (via watch or poll)
    - Existing files at startup (catch-up processing)

    Does NOT monitor /Pending_Approval/facebook/ (FR-010).
    """

    def __init__(self, vault_path: Path, mode: str = "watch"):
        self.vault_path = vault_path
        self.approved_dir = vault_path / "Approved" / "facebook"
        self.mode = mode  # "watch" or "poll"

    def scan_existing(self) -> list[Path]:
        """Return all .md files in /Approved/facebook/ sorted by mtime (oldest first)."""

    def start(self, callback: Callable[[Path], None]) -> None:
        """Start detection. Calls callback for each detected file."""

    def stop(self) -> None:
        """Stop detection."""
```

### 1.3 Startup Catch-Up

On startup, scan `/Approved/facebook/` for existing files and process them in chronological order (oldest first). This handles:
- Executor restart after crash
- Files placed while executor was offline
- Manual file placement

### 1.4 Safety Boundary

**Critical**: Detector MUST only watch `/Approved/facebook/`. It MUST NOT:
- Watch `/Pending_Approval/facebook/`
- Process files from any other directory
- Accept file paths outside the approved directory

```python
def _is_valid_approved_file(self, path: Path) -> bool:
    """Validate file is in /Approved/facebook/ and is markdown."""
    return (
        path.suffix == ".md" and
        self.approved_dir in path.parents and
        "/Pending_Approval/" not in str(path)
    )
```

## Section 2: Facebook Publish Executor

### 2.1 Playwright Session Management

```text
.watcher-state/
└── facebook/
    ├── storage_state.json  # Playwright persistent context storage
    └── publisher.json      # Execution state (processed hashes)
```

**Session persistence**: Use Playwright's `browser_context.storage_state()` to save and load session. This stores cookies and localStorage, allowing subsequent runs to skip login.

**Initial auth**: First run requires headed mode (`headless=False`) for manual Facebook login. User completes login, session is saved. Subsequent runs use headless mode.

### 2.2 Publisher Module

```python
# src/facebook_publisher/executor.py

class FacebookPublisher:
    """Publishes text posts to Facebook via Playwright.

    Workflow:
    1. Launch browser with persistent session
    2. Navigate to Facebook home
    3. Check authentication (re-auth if needed)
    4. Click "What's on your mind?" to open composer
    5. Enter post content
    6. Set visibility (public/friends/only_me)
    7. Click "Post"
    8. Wait for confirmation
    9. Extract post URL if possible
    """

    def __init__(self, session_path: Path, headless: bool = True):
        self.session_path = session_path
        self.headless = headless
        self.browser = None
        self.context = None
        self.page = None

    async def initialize(self) -> None:
        """Launch browser with persistent context."""

    async def is_authenticated(self) -> bool:
        """Check if Facebook session is valid."""

    async def publish_post(self, content: str, visibility: str = "public") -> PublishResult:
        """Publish text content to Facebook.

        Args:
            content: The post text content
            visibility: One of 'public', 'friends', 'only_me'

        Returns:
            PublishResult with success status, post_url, error details
        """

    async def close(self) -> None:
        """Close browser and save session."""
```

### 2.4 Retry Logic (Ralph Wiggum Loop)

```python
async def publish_with_retry(self, content: str, visibility: str, max_attempts: int = 3) -> PublishResult:
    """Publish with retry logic per Constitution Principle V.

    Attempt 1: Execute as planned
    Attempt 2: Re-read selectors, adjust wait times, retry
    Attempt 3: Simplify (longer waits, alternative selectors), retry
    After 3 failures: Return failure result for escalation
    """
    for attempt in range(1, max_attempts + 1):
        try:
            result = await self._attempt_publish(content, visibility, attempt)
            if result.success:
                return result
        except Exception as e:
            if attempt == max_attempts:
                return PublishResult(
                    success=False,
                    error=str(e),
                    error_type=type(e).__name__,
                    retry_count=attempt,
                )
            await self._adjust_for_retry(attempt)

    return PublishResult(success=False, error="Max retries exceeded", retry_count=max_attempts)
```

### 4.2 FacebookLogger Module

Follows the pattern from LinkedIn publisher:

```python
# src/facebook_publisher/logger.py

class FacebookLogger:
    """Logs Facebook publish lifecycle events to /Logs/facebook/.

    Events:
    - detected: File found in /Approved/facebook/
    - validated: Frontmatter passed validation
    - publishing: Publish attempt started
    - published: Post successfully published
    - failed: Publish attempt failed
    - moved_to_done: File moved to /Done/facebook/
    - moved_to_needs_action: File moved due to unrecoverable error
    - duplicate_skipped: Content hash already processed
    """

    def __init__(self, logs_path: Path):
        self.logs_path = logs_path / "facebook"
        self.logs_path.mkdir(parents=True, exist_ok=True)

    def log_event(
        self,
        event: str,
        file_path: str,
        details: Optional[dict] = None,
    ) -> None:
        """Log event as JSON line."""
```

## Section 5: Success/Failure State Handling

### 5.1 Done/Success State Handling

**On successful publish:**

1. Update frontmatter:
   ```yaml
   status: published
   published_at: "2026-03-22T15:00:00Z"
   executed_by: facebook_publisher
   facebook_post_url: "https://..."  # if retrievable
   execution_log: "[[Logs/facebook/facebook-20260322.log]]"
   ```

2. Move file:
   ```
   /Approved/facebook/20260322-143000_post.md
   → /Done/facebook/20260322-143000_post.md
   ```

3. Log event

4. Add content hash to processed state (idempotency)

### 5.2 Failure State Handling

**On transient failure (after 3 retries):**

1. Update frontmatter:
   ```yaml
   status: failed
   last_error: "Network timeout during publish"
   last_attempt_at: "2026-03-22T15:00:00Z"
   retry_count: 3
   ```

2. File remains in `/Approved/facebook/` for manual review

3. Log failure event

4. Do NOT move to `/Needs_Action/` yet (user may want to retry)

**On unrecoverable error (invalid frontmatter, auth failure):**

1. Update frontmatter with error details

2. Move file:
   ```
   /Approved/facebook/20260322-143000_post.md
   → /Needs_Action/facebook/20260322-143000_post.md
   ```

3. Log error event

### 5.3 Processed State File

```json
// .watcher-state/facebook/publisher.json
{
  "processed_hashes": ["abc123...", "def456..."],
  "last_run": "2026-03-22T15:00:00Z",
  "stats": {
    "total_published": 42,
    "total_failed": 3,
    "total_skipped": 5
  }
}
```

### 5.4 Idempotency

Content hash computed from:
```
hash = sha256(action_type + content + source_path)[:16]
```

If hash exists in `processed_hashes`, skip file and log "duplicate_skipped" event.
